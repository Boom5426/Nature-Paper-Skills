# First successful revision / 第一次完成修订

Use this synthetic, self-contained example after installing. It requires no private manuscript, network search, plotting packages or journal account.

1. Open this repository in your agent, or download `draft.md` and `evidence.md` into a working folder.
2. Invoke `paper-workflow` with the prompt below. If it is not available, use the installation guide's discovery check.
3. Inspect the result before opening `expected.md`; that file is one acceptable illustration, not an exact answer to copy.

**English prompt**

> Use paper-workflow. Read examples/first-run/draft.md and examples/first-run/evidence.md. Revise only the Results paragraph using the supplied evidence. Write the revision to examples/first-run/revised.md and briefly explain the material changes. Preserve measured values and figure references.

**中文提示词**

> 用 paper-workflow。读取 examples/first-run/draft.md 和 examples/first-run/evidence.md，依据证据只修改这段 Results。将修订版写入 examples/first-run/revised.md，简要说明关键改动。保留测量值及图号。

Check five things: the 12 cultures, marker effect and interval, survival effect and interval, Fig. 1a/1b, and the absence of an unsupported survival or mechanism claim. The task is complete when the revised paragraph is accurate and readable; a full submission audit is unnecessary.

初次使用完成后，换成自己的当前稿件，并提供相关图表、结果和已经确定的修改范围。无需先建立整套项目笔记。
